## 3. R3 发现并修复的缺陷

### 3.1 本地跨账户归属

原实现没有记录 LocalCapture 属于哪个用户，账号切换后存在本地可见性和错误同步风险。

修复后：

- LocalCapture 持久化 owner_user_id；
- 登录创建时立即绑定当前 user.id；
- 游客 Capture 在首次同步前事务性认领；
- 已归属账号 A 的记录不能转移给账号 B；
- 本地列表按当前账户隔离；
- 同步服务和自动重试调度只观察当前账户或未认领游客记录，避免切换账户后的空转重试风暴。

### 3.2 永久 4xx 无限重试

原实现除 409 外的所有 HTTP 错误都会进入重试，400 等永久错误可能无限唤醒后台任务。

修复后：

- 增加 rejected 本地终态；
- 永久 4xx 移出同步队列并显示“无法同步”；
- 401、408、425、429、网络错误和 5xx 继续保留原文并重试。

### 3.3 无内容上限

原实现未限制文字与请求体大小。

修复后：

- 客户端和服务端统一限制 100,000 个 Unicode code points；
- 创建请求体限制为 1 MiB；
- 空内容和超长内容均有自动化与真实 HTTP 证据。
