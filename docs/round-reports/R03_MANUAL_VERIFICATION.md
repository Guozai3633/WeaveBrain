## A. 真实 Android/iOS 设备验收矩阵

### A.0 准备
1. 开启开发者模式并连接设备：`flutter devices` 应能看到设备。
2. 安装 Debug 包：`flutter run --release` 或 `flutter install`。
3. 确认后端可达：`adb reverse tcp:8083 tcp:8083`（本机后端）或配置远程地址。

### A.1 在线保存（基线）
| # | 步骤 | 预期 |
|---|---|---|
| 1 | 连接网络，进入文字速记，输入「在线测试 1」 | 显示「已安全保存」，卡片入列 |
| 2 | 后端库查询该条存在 | captures / memory_cards 各 1 行 |

### A.2 离线保存 20 条（G1 关键）
| # | 步骤 | 预期 |
|---|---|---|
| 1 | 打开飞行模式（Wi-Fi/蜂窝全断） | 应用仍可用 |
| 2 | 连续保存 20 条文字记忆（可含游客/登录态各 10 条） | 每条显示「已安全保存」 |
| 3 | 记录 20 条文本清单备用 | 无丢失、无重复 |

### A.3 杀进程 + 重启恢复（G1 关键）
| # | 步骤 | 预期 |
|---|---|---|
| 1 | 保持飞行模式，在最近任务中划掉应用（杀进程） | — |
| 2 | 重新打开应用 | 本地列表显示 20 条，状态为「待同步」 |
| 3 | 关闭并重开应用再核对一次 | 仍是 20 条，无重复 |

### A.4 恢复网络同步（G1 关键）
| # | 步骤 | 预期 |
|---|---|---|
| 1 | 关闭飞行模式，恢复网络 | 自动开始同步 |
| 2 | 等待同步完成后核对本地与后端 | 20 条全部同步；后端重复为 0 |
| 3 | 服务端按 capture_id 核对 | 同 UUID 仅 1 条（幂等） |

### A.5 失败路径
| # | 步骤 | 预期 |
|---|---|---|
| 1 | 后端停机（Stop docker 后端），离线保存 1 条 | 显示「已安全保存」，卡片保留 |
| 2 | 重启后端并恢复网络 | 该条最终同步成功 |
| 3 | 同 ID 不同内容提交（在测试代码中构造） | 本地显示冲突，后端返回 409 |
| 4 | 空内容保存 | 客户端不落库、提示错误 |
| 5 | 超 100,000 字符保存 | 客户端不落库、提示错误 |

### A.6 跨用户安全（可选，需两个账号）
| # | 步骤 | 预期 |
|---|---|---|
| 1 | 账号 A 保存 1 条，账号 B 登录 | B 看不到 A 的本地记录 |
| 2 | 用 B 的 token 请求 A 的 capture_id | 返回 404 |

## B. 真实浏览器 IndexedDB 验收

> 说明：`flutter test --platform chrome` 在本机因测试 harness 无法加载（「Connection closed before test suite loaded」），故改为在真实浏览器中人工验证 sembast_web IndexedDB 持久化。

### B.1 准备
1. `flutter build web --debug` 成功。
2. 用本地静态服务器托管 `build/web`（避免 file:// 下 IndexedDB 限制）：
   ```bash
   cd weave_flutter/build/web && python -m http.server 8088
   ```
3. 打开 Chrome/Edge：`http://localhost:8088`。

### B.2 步骤
| # | 步骤 | 预期 |
|---|---|---|
| 1 | DevTools → Application → IndexedDB，记录当前数据库名（应为 `sembast_web`） | 可见数据库句柄 |
| 2 | 断网（DevTools Network → Offline） | 应用仍可操作 |
| 3 | 保存 20 条文字记忆 | 每条显示「已安全保存」 |
| 4 | DevTools → Application → IndexedDB，展开数据库 | 20 条记录可见 |
| 5 | 关闭该标签页（完全关闭，非刷新） | — |
| 6 | 重新打开 `http://localhost:8088` | 本地列表显示 20 条，状态「待同步」 |
| 7 | 恢复网络（Network → Online） | 自动同步；后端 20 条且重复为 0 |
| 8 | 再关闭标签页重开一次 | 仍为 20 条，无重复 |
